# 🤖 Skill Gap Analyzer Bot

An AI-powered Skill Gap Analyzer Bot built using **n8n** and **OpenAI**.

This automation analyzes a user's resume/CV, identifies missing or weak skills, provides career-focused recommendations, stores the analysis in Google Sheets, and sends the result to the user via email.

---

## 🚀 Project Overview

The Skill Gap Analyzer Bot helps users understand:

- What skills they currently have
- Which skills are missing
- Which skills need improvement
- Recommended skills to learn
- Career improvement suggestions

The complete process is automated using an **n8n workflow**.

---

## 🔄 Workflow

The workflow follows these steps:

1. 📋 User submits the form
2. 📄 Resume/CV PDF is uploaded
3. 🔍 PDF content is extracted
4. 🤖 AI Agent analyzes the resume
5. 🧠 OpenAI Chat Model processes the information
6. 💻 JavaScript formats the AI response
7. 📊 Result is added to Google Sheets
8. 📧 Analysis is sent to the user via email
